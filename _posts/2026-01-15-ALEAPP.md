# ALEAPP – Android Logs, Events, and Protobuf Parser

## Category
**Endpoint Forensics / Mobile Forensics**

## Tool Type
**Open-source Android forensic analysis framework**

---

## What is ALEAPP?

**ALEAPP (Android Logs, Events, and Protobuf Parser)** is an open-source digital forensics tool designed to **parse, analyze, and correlate forensic artifacts from Android devices**.

It automates the extraction and interpretation of data from Android system logs, application databases, protobuf files, and other internal artifacts commonly encountered during mobile forensic investigations.

ALEAPP is part of the **LEAPP framework family**, alongside:

- **iLEAPP** (iOS forensics)
- **aLEAPP** (Android forensics)

---

## What Does ALEAPP Do?

ALEAPP processes Android forensic data obtained from:

- Logical extractions  
- File system dumps  
- ADB backups  
- Parsed acquisition tools  

It converts raw Android artifacts into **human-readable forensic reports**, helping investigators quickly reconstruct user activity.

---

## Key Capabilities

ALEAPP can analyze and extract:

- 📱 Installed applications  
- 📍 Location & GPS history  
- 💬 SMS and messaging artifacts  
- 📞 Call logs  
- 🌐 Browser history  
- 🗺️ Google Maps activity  
- 📆 Timestamps & timelines  
- 📂 App databases (SQLite)  
- 🔐 Account and authentication artifacts  
- 🧾 Financial and trading app data  
- 🧠 User behavior reconstruction  

### Output Formats

- HTML reports  
- CSV files  
- JSON format  

---

## Why ALEAPP is Important in Forensics

Android devices store data across:

- SQLite databases  
- Protobuf files  
- XML configuration files  
- Cached application data  

Manually analyzing these artifacts is **time-consuming and error-prone**.  
ALEAPP automates this process and ensures consistency in forensic investigations.

## Installation & Setup

ALEAPP is written in **Python**, making it easy to deploy across platforms.

---

## 🔧 Setting Up ALEAPP on Linux

### Prerequisites

```bash
sudo apt update
sudo apt install -y python3 python3-pip git

Installation

git clone https://github.com/abrignoni/ALEAPP.git
cd ALEAPP
pip3 install -r requirements.txt

Running ALEAPP
python3 aleapp.py

Analysis Example
python3 aleapp.py -t fs -i /path/to/android/artifacts -o /path/to/output_directory

🔧 Setting Up ALEAPP on Windows
Prerequisites

Install Python 3.8+

Enable Add Python to PATH

Install Git for Windows

Installation
git clone https://github.com/abrignoni/ALEAPP.git
cd ALEAPP
pip install -r requirements.txt

Running ALEAPP
python aleapp.py

Analysis Example
python aleapp.py -t fs -i C:\ForensicData\AndroidDump -o C:\ALEAPP_Reports
