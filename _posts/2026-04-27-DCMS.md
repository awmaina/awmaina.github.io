## Project Overview

The **Dental Clinic Management System (DCMS)** is my KCA University Final Year Project — a full-stack web application built for **Dr. Smile Dental Clinic** to replace entirely manual, paper-based operations with a secure, role-based digital platform.

> **Stack:** PHP 8.2 · MySQL · JavaScript · M-Pesa Daraja API · SVG Odontogram  
> **Supervisor:** Madam Mercy Mukani · **Academic Year:** 2025/2026

---

## The Problem

The clinic ran on a paper appointment ledger, physical patient file folders, and a spreadsheet for billing. This created four compounding problems:

- **Double-bookings** — no real-time slot visibility across practitioners
- **Insecure patient data** — physical files were slow to retrieve and posed a security risk
- **No clinical charting standard** — no odontogram meant subjective, inconsistent procedure records
- **Manual billing errors** — spreadsheet invoicing with no financial reporting capability

---

## What I Built

The DCMS is a three-tier web application with four core modules, serving three distinct user roles (Administrator, Dentist, Receptionist) enforced through RBAC middleware.

| Module | Key Capability |
|---|---|
| **Appointment Scheduling** | Real-time conflict detection (TIMESTAMPDIFF ±30 min buffer), CRUD, SMS/email reminders |
| **EHR & Patient Records** | Instant record retrieval (<5s), clinical notes with electronic sign-off, patient search |
| **Odontogram** | Anatomical SVG tooth chart (FDI two-digit notation), colour-coded treatment status |
| **Billing & Reporting** | Auto-invoice on appointment completion, M-Pesa STK Push, monthly revenue reports |

## Key Technical Highlights

### Double-Booking Prevention (F-1.2)

```php
$stmt = $pdo->prepare(
    'SELECT id FROM appointments
     WHERE dentist_id = ?
     AND appointment_date = ?
     AND ABS(TIMESTAMPDIFF(MINUTE, appointment_time, ?)) < 30
     AND status NOT IN ("Cancelled")'
);
$stmt->execute([$dentist_id, $date, $time]);

if ($stmt->rowCount() > 0) {
    echo json_encode(['conflict' => true]);
    exit;
}
```

### M-Pesa STK Push Integration

```php
function formatPhone($phone) {
    if (substr($phone, 0, 1) === '0') {
        return '254' . substr($phone, 1);
    }
    return $phone;
}

$response = sendSTKPush(formatPhone($patient_phone), $amount, $description);
// Safaricom callback → invoice status = 'Paid'
```
